# CreditFlow — C4 Architecture

> Source of truth: `CreditFlow/README.md` architecture diagram
> (validate → features → ML → threshold → LangGraph → disbursement → ledger).
> Private on-prem deployment: CONFIDENTIAL never leaves the VPC.

## C4-Context

```mermaid
C4Context
    title CreditFlow — System Context
    Person(off, "Loan officer", "submits, reviews, approves + signs slip")
    Person(mgr, "Branch manager", "second signature on decision slip")
    System(cf, "CreditFlow", "cost-tuned ML decision + ledgered disbursement")
    System_Ext(mlf, "MLflow", "experiments, registry")
    System_Ext(vllm, "Private vLLM", "memo generation, CONFIDENTIAL-safe")
    Rel(off, cf, "applies, approves REVIEW", "HTTPS")
    Rel(mgr, cf, "countersigns", "HTTPS")
    Rel(cf, mlf, "tracks", "API")
    Rel(cf, vllm, "explains (never decides)", "VPC")
```

## C4-Container

```mermaid
C4Container
    title CreditFlow — Containers
    Person(off, "Loan officer", "React 18 UI")
    Container_Boundary(c, "CreditFlow") {
        Container(api, "FastAPI backend", "Python", "validate, score, decide, disburse")
        Container(ml, "ML pipeline", "sklearn + LogReg t=0.20", "5 features, cost threshold")
        Container(flow, "LangGraph 12-node", "Python", "REVIEW interrupt/resume, audit")
        Container(ui, "React frontend", "Vite", "apply, slips @media print")
        ContainerDb(led, "SQLite ledger", "file", "HDTD contracts + SHA-256 chain")
    }
    Rel(off, ui, "uses", "HTTPS")
    Rel(ui, api, "calls", "HTTP")
    Rel(api, ml, "scores", "in-process")
    Rel(api, flow, "orchestrates", "in-process")
    Rel(flow, led, "disburses idempotently", "SQL")
```
